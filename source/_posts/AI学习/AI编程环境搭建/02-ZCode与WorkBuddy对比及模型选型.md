# 第 2 篇：认识 ZCode，搞清工具与模型怎么选

> **一句话结论**
> **工具上**：WorkBuddy 是「办公 + 代码都能干」的全场景智能体，ZCode 是「专攻写代码」的氛围编程工具，**建议两个都装，按任务切换**。
> **模型上**：想「随便写、不怕账单」→ **GLM Coding Plan**（订阅封顶）；想「用多少付多少」→ **DeepSeek 官方 API**（按量计费）。两者不冲突，最后两节教你**同时接上**。

## 一、ZCode：智谱出品的氛围编程工具

### 1.1 基本信息

| 项目 | 内容 |
| :--- | :--- |
| 出品方 | 智谱 AI（Z.ai） |
| 官网 / 下载页 | <https://zcode.z.ai/cn> |
| 定位 | 「GLM-5.3 官方 Harness」，新一代 vibe coding 工具 |
| 支持平台 | **Windows x64**、**macOS**（Apple 芯片 / Intel）、Linux（beta 通道） |
| 收费 | **客户端免费下载**；模型访问需 GLM Coding Plan 订阅，或自带 API Key |

### 1.2 安装步骤

```
① 打开 https://zcode.z.ai/cn
      ↓
② 下载对应安装包
   · Windows → .exe 安装包，双击运行，保持默认安装路径
   · macOS   → .dmg，拖进「应用程序」文件夹
      ↓
③ 从开始菜单 / 启动台打开 ZCode
      ↓
④ 选择模型来源（下面三种选一个）
```

**第四步的三种模型来源：**

| 方式 | 说明 | 适合谁 |
| :--- | :--- | :--- |
| **GLM Coding Plan 订阅** | 登录智谱开放平台账号自动绑定 | 整天写代码、用量大的人 |
| **自带 API Key（BYOK）** | 填 Base URL + API Key + 模型名 | 已买 DeepSeek / 其他模型的人 |
| **限时免费窗口** | 官方不定期开放免费额度 | 只想先试试手感的人 |

> 📌 **当前最划算的玩法**：GLM Coding Plan 正在做「夜间畅用活动」，详见 [2.3 节](#sec-glm-night)。

**命令行启动（推荐给习惯终端的人）：**

```bash
cd ~/projects/my-app
zcode .
```

### 1.3 它的拿手功能

- **对话即执行**：直接改本地文件、跑 Shell 命令、查看 diff
- **多智能体协作**：多个 Agent 分工啃复杂目标
- **Goal Mode**：把一句目标变成可续跑的任务，自动「规划 → 实现 → 测试 → 修复」直到跑通
- **版本管理**：以对话为时间轴，随时回滚到任意节点
- **内置终端 / 文件管理器 / Git 面板 / 浏览器预览**：基本不用切窗口
- **远程连接**：通过 SSH 让 AI 在远程服务器上干活

## 二、WorkBuddy 与 ZCode 到底有什么区别

| 对比维度 | **WorkBuddy** | **ZCode** |
| :--- | :--- | :--- |
| 出品方 | 腾讯 | 智谱 AI |
| 核心定位 | 全场景 AI **办公**工作台 | 专业 AI **编程**工具 |
| 交互模型 | 说需求 → 交付文件 | 对话 → 直接改代码库 |
| 输出形态 | 文档 / 表格 / PPT / 报告 | 代码变更 / diff / 提交 |
| 擅长 | 办公自动化、数据处理、调研、批量文件 | 写代码、重构、调试、跑测试 |
| 本地文件操作 | ✅ 授权文件夹读写 | ✅ 直接读写项目仓库（更强） |
| 多智能体 | ✅ 100+ 领域专家团 | ✅ 多 Agent 协作 |
| 远程控制 | ✅ 桌面 / 主流 IM / 小程序 | ✅ SSH 远程服务器 |
| 收费方式 | **积分制**，新人积分免费 | 客户端免费，**模型订阅 / 自带 Key** |
| 上手门槛 | **极低**，装完就能用 | 中等，要选模型来源 |
| 配环境 / 装软件 | ✅ **强项**（本教程第 3、5 篇就用它） | ✅ 可以，但要自己开口子 |
| 从零写大项目 | ⚠️ 一般，不推荐 | ✅ **强项** |
| 适合谁 | 想用 AI 提效的**所有人** | **开发者 / 长期写项目的人** |

### 用一张图做决策

```
你要用它做什么？
│
├── 写文档、做表格、出 PPT、做调研、整理文件
│        └──→ 【WorkBuddy】✅ 首选
│
├── 配环境、装软件、处理本地文件
│        └──→ 【WorkBuddy】✅ 首选（本教程的做法）

├── 写代码、改代码、重构、调试、跑测试
│        └──→ 【ZCode】✅ 首选
│
└── 两个都要
         └──→ 【都装】✅ 本文推荐
                    · WorkBuddy 负责「办公交付 + 环境配置」
                    · ZCode 负责「代码工程」
                    · 两者都能接 DeepSeek API（见本文附录）
```

> 🔑 **记住这句话就够**：聊天工具替你「**说**」，WorkBuddy 替你「**做**」，ZCode 替你「**写**」。
> 本教程全程用 **WorkBuddy**——因为它的强项正是「帮你在真实电脑环境里把事情做出来」。

#### （3）⭐ 按量计费的四个优势

**1）零门槛起步，不用不花钱**

不需要月费、不需要承诺周期。充 10 块钱就能用，这个月没用完，余额**留到下个月继续用**，不会像订阅那样「过了 1 号就白扣」。

**2）天然抗浪费，用量和支出严格成正比**

订阅制的痛点在于「**用不满就是浪费**」——一个月只用了 3 天，$18 照样扣。按量计费的账单一分不差地等于真实消耗，**轻度使用者几乎总是按量更划算**。

**3）缓存命中价差最高 50 倍，长提示词场景极省**

输入缓存命中 **0.02 元**，未命中 **1 元**——**相差 50 倍**。
这意味着：固定的系统提示词、知识库、历史对话这些「反复出现的上下文」，第二次起几乎不要钱。对 **代码助手、RAG 应用、客服机器人、Agent** 这类场景，降本效果非常明显。

**4）闲时半价 + 1M 超长上下文不加价**

- 批量任务、脚本跑批放到**晚上或周末**，直接**半价**。
- 1M 上下文不额外收「长上下文附加费」，喂长文档、大代码库不用心疼。

**什么时候按量反而更贵？** 当你**整天挂着 Agent 写代码**时，一天可能烧掉 20 万～50 万 tokens，累积下来会超过 $18 的月费。这时候**订阅制的封顶**才更香。

## 四、⭐ 换模型：怎么切、推荐哪两个、怎么开到 1M 上下文

### 4.1 三种切换方式

**方式一：会话内即时切换（最常用）**

```
输入框右侧 → 点当前模型图标
      ↓
从下拉菜单里选目标模型
      ↓
回车发送，本次会话后续全部由该模型执行
```

✅ 不用重启、不影响其他会话。想横向对比两个模型的输出，这样切最快。

**方式二：设置里添加自定义模型（想接自己的 API）**

```
设置 → 模型管理 → 添加自定义模型
      ↓
协议选：【OpenAI 兼容】
      ↓
填三项：Base URL / API Key / 模型 ID
      ↓
保存 → 点「测试连接」
```

**方式三：设为默认 + 故障自动切换**

在「模型管理」里把常用模型**设为默认**，还可以配置「主模型失败时自动切换到备用模型」，避免单点故障把长任务卡死。

### 4.2 推荐这两个模型

| 推荐 | 模型 ID | 上下文 | 亮点 | 建议用途 |
| :--- | :--- | :---: | :--- | :--- |
| **DeepSeek V4.1 Flash** | `deepseek-flash` | **1M** | 按量计费，**闲时半价**；缓存命中低至 0.02 元/百万 token；最大输出 384K | **日常主力**，省钱首选 |
| **GLM-5.3 Flash** | `glm-5.3-flash` | **1M** | **原生多模态**（文本 / 图片 / 视频 / 文件）；在 Coding Plan 里额度是 GLM-5.3 的 **3 倍**；最大输出 128K | **夜间免费窗口** + 需要看图看视频的任务 |

**接入参数速查：**

| 模型 | Base URL（OpenAI 兼容） | 模型 ID |
| :--- | :--- | :--- |
| DeepSeek V4.1 Flash | `https://api.deepseek.com/v1` | `deepseek-flash` |
| GLM-5.3 Flash | `https://open.bigmodel.cn/api/paas/v4/` | `glm-5.3-flash` |

> ⚠️ 客户端里的 Base URL 通常要填**完整接口路径**（以 `/chat/completions` 结尾，或按界面提示补 `/v1`）。填完**一定点「测试连接」**，通过再往下走。

### 4.3 怎么把上下文开到 1M

**关键点：模型支持 1M ≠ 客户端会给你 1M。** 添加/编辑模型时，必须**手动把「最大输入 tokens」填成 1M**；不填的话客户端会用默认的小值，长文档会被**悄悄截断**。

**推荐填写值：**

| 字段 | DeepSeek V4.1 Flash | GLM-5.3 Flash |
| :--- | ---: | ---: |
| 最大输入 tokens（上下文） | **1048576** | **1048576** |
| 最大输出 tokens | 262144 | 131072 |

**两种改法：**

- **图形界面**：模型管理里点该模型的「编辑 / 配置」→ 找到「最大输入 tokens」「最大输出 tokens」→ 改成上表数字 → 保存。
- **配置文件**（进阶）：编辑 `C:\Users\<你的用户名>\.codebuddy\models.json`，把 `maxInputTokens` 写成 `1048576`（完整示例见 [附录 A](#sec-addapi)）。

> 📌 **一定要知道的代价**：把上限开到 1M 只是**解除限制**，不代表免费。
> 1M 上下文意味着**单次请求可能吃掉上百万输入 token**——按量计费下这是真金白银。
> DeepSeek 那个 0.02 元/百万 token 的超低价，**只有在相同前缀被重复命中缓存时才成立**。
> 日常对话几十 K 上下文就够，**别为了「开着爽」把 1M 顶满**。

| 级别 | 路径 | 说明 |
| :--- | :--- | :--- |
| **用户级** | `C:\Users\<你的用户名>\.codebuddy\models.json` | 对所有项目生效 |
| **项目级** | `<你的项目目录>\.codebuddy\models.json` | 只对该项目生效，**优先级更高** |

**先把 Key 设为环境变量**（避免密钥写死在文件里）：

```powershell
setx DEEPSEEK_API_KEY "sk-你的DeepSeek密钥"
```

**再写入配置**：

```json
{
  "models": [
    {
      "id": "deepseek-flash",
      "name": "DeepSeek V4.1 Flash",
      "vendor": "DeepSeek",
      "url": "https://api.deepseek.com/v1/chat/completions",
      "apiKey": "${DEEPSEEK_API_KEY}",
      "maxInputTokens": 1048576,
      "maxOutputTokens": 262144,
      "supportsToolCall": true,
      "supportsImages": true,
      "supportsReasoning": true
    }
  ],
  "availableModels": [
    "deepseek-flash"
  ]
}
```

**三个坑，务必注意：**

1. `url` 必须是**完整接口路径**，以 `/chat/completions` 结尾。
   ✅ `https://api.deepseek.com/v1/chat/completions`
   ❌ `https://api.deepseek.com/v1`
2. 配置文件请**保存为 UTF-8 无 BOM**。带 BOM 会导致配置加载失败。
3. 配置文件**支持热重载**，改完保存即可生效，一般不用重启。若未生效，重启客户端。

## 五、常见问题

**Q1：两个软件会不会冲突？**
不会。它们是独立客户端，可以同时安装、同时运行。

**Q2：本教程为什么全程用 WorkBuddy 而不是 ZCode？**
因为本教程的重点是「**在真实电脑环境里把事情做出来**」——装软件、配环境变量、建项目、跑命令，这正是 WorkBuddy 的强项。等你环境搭好了，真要长期写代码时，再切到 ZCode 效率更高。

**Q3：GLM 的「夜间免费」是永久的吗？**
不是。活动期明确是 **2026 年 9 月 3 日至 9 月 20 日**，之后规则以官方公告为准。

**Q4：DeepSeek 的「缓存命中」是什么意思？**
模型之前已经处理过的内容，后续请求可直接复用、无需重新计算。固定系统指令、长提示词、连续对话最容易命中。命中率越高越省钱——**把固定内容放前面、动态内容放后面**，是最实用的省钱技巧。

**Q5：订阅的额度用完了会怎样？**
**直接停**，不会自动续、不会产生超额费用，等到 5 小时 / 周限额重置后恢复。所以**开工前先看一眼剩余额度**是个好习惯。

**Q6：一定要花钱吗？**
不一定。WorkBuddy 有免费积分（见 [第 1 篇 4.3 节](01-VSCode与WorkBuddy安装与汉化.md#sec-wb-points)）；
ZCode 客户端永远免费，成本只在模型上——可以先用限时免费额度，或直接按量付费接 DeepSeek（**不用不花钱**）。
