# 第 1 篇：装好 VSCode 与 WorkBuddy，并把界面换成中文

> **一句话结论**
> 这一篇只干三件事：**装 VSCode（写代码的编辑器）→ 把它汉化成中文 → 装 WorkBuddy（帮你干活的 AI）**。
> 关于 Python 环境，本篇只讲清「**我们要装什么、为什么要这么装**」，**真正动手在第 3 篇**——那里会交给 WorkBuddy 自动完成。
> 全程不需要命令行，一路「下一步」即可。

![VSCode + WorkBuddy + Python 三件套](/images/AI编程环境搭建/01-install-overview.svg)

---

## 一、先看清：这一篇要装的三样东西

| 顺序 | 软件 | 它是干什么的 | 装完的标志 |
| :---: | :--- | :--- | :--- |
| ① | **VSCode** | 写代码的编辑器（微软官方，**免费**） | 打开能看到欢迎页 |
| ② | **中文语言包** | 把 VSCode 的英文菜单变成中文 | 菜单栏显示「文件 / 编辑 / 查看」 |
| ③ | **WorkBuddy** | 腾讯出品的 AI 智能体，**后面的环境配置全靠它** | 扫码登录成功、能对话 |

> 💡 **Python 环境不在这一篇装**。第 1 篇的第五节会先给你讲全貌，
> 第 3 篇再让 WorkBuddy 一条提示词帮你装好 —— **在那之前不要自己去 python.org 下载安装包**。

## 二、安装 VSCode

### 2.1 下载

| 项目 | 内容 |
| :--- | :--- |
| 官网 | <https://code.visualstudio.com/> |
| 支持平台 | Windows / macOS / Linux |
| 费用 | **完全免费**（微软官方，开源） |
| 安装包 | Windows 约 100 MB 的 `.exe` |

打开官网，点页面上的 **Download for Windows** 即可。

> ⚠️ 注意别点到页面上的广告位或第三方下载站的「高速下载」。**认准 `code.visualstudio.com` 这个域名**。

### 2.2 安装时务必勾选的几项

双击安装包，同意协议后，到「**选择附加任务**」这一页，**建议全部勾上**，尤其是这四项：

| 选项 | 为什么要勾 |
| :--- | :--- |
| ☑ **将「通过 Code 打开」操作添加到文件上下文菜单** | 以后右键 `.py` 文件就能直接打开 |
| ☑ **将「通过 Code 打开」操作添加到目录上下文菜单** | 以后右键文件夹就能直接打开（**第 4、5 篇要用**） |
| ☑ **将 Code 注册为受支持的文件类型的编辑器** | 双击 `.py` 默认用 VSCode 打开 |
| ☑ **添加到 PATH** | 之后可以在终端里敲 `code .` 打开当前目录 |

**安装路径**：保持默认即可；想省系统盘可以改到 D 盘，但**路径里不要出现中文或空格**。

### 2.3 验证安装

装完打开 VSCode，看到欢迎页就成功了。想确认命令行也能用，在终端里敲：

```powershell
code --version
```

能输出三行版本号（形如 `1.9x.x`）就说明 PATH 也生效了。

## 三、把 VSCode 汉化成中文

VSCode 默认界面是英文。装一个官方语言包即可变中文，**三种方式任选其一**。

### 方式一：扩展市场（最直观，推荐新手）

```
① 打开 VSCode
      ↓
② 按 Ctrl + Shift + X 打开「扩展」面板
      ↓
③ 搜索框输入：Chinese
      ↓
④ 找到：Chinese (Simplified) (简体中文) Language Pack
   —— 发布者必须是【Microsoft】，别装错了
      ↓
⑤ 点「Install / 安装」
      ↓
⑥ 右下角弹提示 → 点「Change Language and Restart」（更改语言并重启）
```

重启后，菜单栏变成「文件 / 编辑 / 查看 / 运行 / 终端 / 帮助」就对了。

### 方式二：命令面板

```
① 按 Ctrl + Shift + P 打开命令面板
      ↓
② 输入并选择：Configure Display Language
      ↓
③ 选择「中文（简体）」→ 按提示重启
```

### 方式三：命令行一条搞定

```powershell
code --install-extension ms-ceintl.vscode-language-pack-zh-hans
```

装完重启 VSCode 生效。

> 💡 **搜不到 / 一直转圈怎么办？**
> 多数是网络问题，重试几次通常就好；国内网络访问扩展市场偶尔偏慢，这是正常的。
> 也可以在扩展面板右上角的 `...` 菜单里切换扩展商店源。

### 4.1 基本信息

| 项目 | 内容 |
| :--- | :--- |
| 出品方 | 腾讯 |
| 官网 / 下载页 | <https://www.codebuddy.cn/work> |
| 官方文档 | <https://www.workbuddy.cn/docs/workbuddy/Overview> |
| 支持平台 | **Windows 10+**（x64，兼容 ARM64）、**macOS 12.0+**（Intel / Apple 芯片）、Linux（统信 UOS、银河麒麟，走系统应用商店） |

### 4.2 安装步骤（约 1 分钟）

```
① 打开 https://www.codebuddy.cn/work

② 认准系统版本下载
   · Windows → 点「Windows x64」，下载 .exe
   · Mac     → 按芯片型号下对应 .dmg（Intel / Apple 芯片别下错）

③ 双击安装包，一路「下一步」（组件建议全选）
```

三个小提醒：

- **安装路径**：默认装 C 盘也行；想省系统盘可改到 D 盘，但**路径里不要出现中文**。
- **组件选择**：建议全选，避免后面缺依赖再补装。
- **桌面快捷方式**：勾上，后面几篇会频繁用到。

整个过程**不需要命令行，也不需要手动配环境变量**。

### 4.3 ⭐ 免费积分怎么领（重点，很多人漏掉）

积分就是 WorkBuddy 运行任务的「燃料」。免费积分有**四条路**，登录后**一定要挨个领一遍**：

![WorkBuddy 免费积分获取路径](/images/AI编程环境搭建/01-points.svg)

| 顺序 | 名称 | 大概额度 | 领取位置 | 备注 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | **新人礼包** | 约 2800 ~ 5000 分 | 左下角头像 → 个人中心 → 使用量 / 礼包 | **需要手动点一下才到账**，有效期约 90 天 |
| 2 | **每月固定积分** | 500 分 / 月 | 每月 1 日自动到账 | 永久有效，轻度办公足够 |
| 3 | **每日签到** | 约 100 ~ 150 分 / 天 | 左下角头像 → 今日礼包 | 每天点一下，连续 7 天有加成 |
| 4 | **成长计划任务** | 一次性 900 分 | 个人中心 → 成长计划 | 「首次对话」「生成第一份文档」等任务都算 |

**积分消耗参考**（心里有个数）：

- 简单问答 / 短句改写：10 ~ 30 分
- 周报 / 总结 / 文案：30 ~ 50 分
- 表格整理 / 长文排版：50 ~ 150 分
- 复杂方案 / PPT 大纲：200 ~ 800 分

> 💡 **第 3 篇、第 5 篇都要让 WorkBuddy 帮你配环境，会消耗积分。**
> 所以**现在就把四条路的积分全领了**，后面才不会卡在半路。

**积分不够用了怎么办？** 去腾讯云开发者社区发文是最「香」的渠道：

| 内容类型 | 奖励 |
| :--- | :--- |
| 心得 / 体验 | 500 分 / 篇 |
| 教程 / 实战 | 1000 分 / 篇 |
| 被官方精选 | 额外 +2000 分 |
| 每月上限 | 48000 分 |

### 4.4 两个权限模式，别用错

| 模式 | 能做什么 | 适合场景 |
| :--- | :--- | :--- |
| **默认权限** | 对话、问答、生成文档；**动不了本地文件和终端** | 查资料、问概念、写文案 |
| **允许完全访问** | **读写文件、执行终端命令** | **真正干活**：配环境、改代码、跑命令 |

> ⭐ **第 3 篇和第 5 篇必须切到「允许完全访问」**——只有这个模式能让它读写文件、执行终端命令。
> 平时问答用「默认权限」就行；要让它动手干活，再切「允许完全访问」。

### 4.5 它能干什么

- **写代码 / 配环境**：本篇教程的核心用途，第 3、5 篇会实际用到
- **文档生成**：工作报告、技术文档、会议纪要
- **数据分析**：丢一个数据文件进去，自动分析并出可视化
- **PPT / 报告**：从一句需求生成完整演示文稿
- **深度研究**：多源检索后输出调研报告
- **批量文件处理**：自动整理、重命名、转换格式

## 五、Python 环境怎么装（先看全貌，第 3 篇动手）

**这一节只讲思路，不要现在动手。**

### 5.1 三个名词，30 秒搞清

| 名词 | 是什么 | 打个比方 |
| :--- | :--- | :--- |
| **Python 解释器** | 真正执行 `.py` 代码的程序 | 发动机 |
| **包（依赖）** | 别人写好的功能库，如 `requests` | 配件 |
| **虚拟环境** | 每个项目**独立**的一份「解释器 + 依赖」 | 每辆车自己的油箱 |

**为什么要虚拟环境？** 项目 A 要 2.0 版的库，项目 B 要 3.0 版，**装在一起就会打架**。
虚拟环境让每个项目互不干扰——**这是专业做法，也是本教程的做法**。

### 5.2 传统做法的三个坑

| 环节 | 传统做法 | 坑在哪 |
| :--- | :--- | :--- |
| 装 Python | 去 python.org 下安装包，手动勾「Add to PATH」 | 忘记勾选 → 命令行找不到 python；以后想删干净很麻烦 |
| 建虚拟环境 | `python -m venv .venv` + 手动激活 | 每次开终端都要先激活，忘了就装错地方 |
| 装依赖 | `pip install`（慢） | 一个大项目装几分钟是常事 |

### 5.3 我们的方案：用 uv

**uv** 是「Python 版本管理器 + 包管理器 + 虚拟环境管理器」三合一的工具，**一条命令装好 Python**。

| 环节 | 传统做法 | 用 uv |
| :--- | :--- | :--- |
| 装 Python | 官网下安装包 + 手动勾 PATH | `uv python install 3.12` |
| 切换版本 | 卸载重装，或折腾 pyenv | `uv python install 3.11 3.12` 共存 |
| 建虚拟环境 | `python -m venv .venv` + 激活 | `uv venv` |
| 装依赖 | `pip install`（慢） | `uv add requests`（快一个数量级） |
| 运行 | 先激活再 `python xxx.py` | `uv run xxx.py`（自动用对的环境） |
| 换电脑复现 | 一堆手动步骤，容易漏 | `uv sync` |

**总结成一句话**：uv 把「装解释器 → 建虚拟环境 → 装依赖 → 运行」收敛成几条命令，**且完全不污染系统 Python**。

> 📖 **uv 到底是什么、它强在哪、东西都装到哪些文件夹？**
> 深入讲解见 [第 3 篇 · 第一节「先认识 uv」](03-用WorkBuddy安装uv与Python3.12.md#sec-what-is-uv)。
> 本篇只需要先记住结论：**我们用 uv 来装 Python，不用去官网下安装包。**

## 七、常见问题

**Q1：VSCode 和 WorkBuddy 是不是二选一？**
不是，**两个都要装**。VSCode 是你写代码的地方，WorkBuddy 是帮你写、帮你配环境的 AI。
第 5 篇会演示它俩怎么配合。

**Q2：Windows 7 能用吗？**
VSCode 可以用；但 **WorkBuddy 要求 Win10 及以上**，老系统请先升级。

**Q3：扩展市场搜不到中文语言包？**
检查网络后重试；或在扩展面板右上角 `...` 里切换商店源；公司网络可能需要配代理。

**Q4：WorkBuddy 一定要花钱吗？**
不一定。把免费积分四条路全领一遍，跑完本教程完全够用；不够再考虑充值或发文赚积分。

**Q5：登录账号有什么讲究？**
建议与腾讯云开发者社区账号保持一致，这样**积分才能互通、发文奖励才能到账**。

**Q6：装软件需要管理员权限吗？**
安装 VSCode 和 WorkBuddy 需要。后面配环境变量只用**用户级**，不需要管理员。
